🔄 Key User Flows

1. Quiz Flow

Hero CTA → Quiz Modal (12 questions) → Element Result → Subtype Quiz (6 questions) → Full Result → Save to Profile

2. Authentication Flow

Sign In Button → Auth Modal → Email/Password → Supabase Auth → Profile Load → Sync Quiz Results

3. Premium Upgrade Flow

Premium Gate → Membership Section → Select Plan → Stripe Checkout → Subscription Active → Unlock Features

4. Selfie Analysis Flow

Upload Photo → AI Analysis → Undertone Detection → Element Match → Subtype Recommendation → Save Result

5. Wardrobe Analysis Flow

Upload Clothing Photo → Color Extraction → Palette Comparison → Compatibility Score → Suggestions

6. Consultation Booking Flow

Select Expert → Choose Time → Apply Premium Discount → Payment → Confirmation Email

💾 Core Data Models

Elemental Types (4)

Fire (Summer), Water (Winter), Earth (Autumn), Air (Spring) - each with unique colors, traits, and imagery.

Subtypes (16)

4 subtypes per element based on secondary influence: Pure, +Fire, +Water, +Earth, +Air combinations.

User Profile

elemental_type, elemental_subtype, membership_tier, saved_hair_colors, quiz_history, preferences.

Subscription

tier (free/premium/pro), stripe_customer_id, subscription_status, current_period_end.

⚙️ Technology Stack

Frontend

React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui components

State Management

React Context (Auth, App), React Query for server state

Backend

Supabase (Auth, Database, Edge Functions, Storage)

Payments

Stripe (Subscriptions, Checkout Sessions)

AI Features

OpenAI Vision API for selfie analysis

Routing

React Router v6 (minimal routes, scroll-based navigation)
